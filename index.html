What it does

A VM you can read in one sitting

⚙️

22 instructions

Arithmetic, comparison, control flow, memory. Nothing more.

🧮

256 registers

r0 through r255, all 64-bit signed.

🧠

Bounds-checked memory

Flat 65536-cell address space. Out-of-bounds access is a clean error, not a segfault.

🛡

Safe by default

Division-by-zero detection, step limits, labeled errors with line numbers.

Install

Grab a binary, run it

linux · arm64
curl -L https://github.com/Humbulan/shab-polyglot/releases/latest/download/shab-linux-arm64 -o shab
chmod +x shab
sudo mv shab /usr/local/bin/
from source
git clone https://github.com/Humbulan/shab-polyglot.git
cd shab-polyglot
make
make test
